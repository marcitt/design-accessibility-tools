# 5-Evaluation

To evaluate the prototype and RQ2 a mixed methods approach was used.
SUS scores, NASA-(R)TLX scores, task completion times and qualitative comments were all gathered to help with the evaluation.

ELAN was used to work out task completion times. 
The raw ELAN export are available in: `5-Evaluation/Quantitative_Analysis/raw-data`
but they were converted into more structured CSV formats for `5-Evaluation/Quantitative_Analysis/data` subsequent analysis.

SUS and NASA-RTLX scores originate from `SUS_RTLX_template.xlsx` and were converted into `sus_rtlx_long.csv` and `sus_rtlx_summary.csv` using some helper tools generated with Claude Sonnet 4.6.

Then the respective descriptive and inferential statistics Jupyter Notebooks are available for the data - with the split being between subjective data (SUS/RTLX) and objective data (task completion time)
